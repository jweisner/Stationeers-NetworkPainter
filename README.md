# NetworkPainter (fork): archived

This fork is no longer maintained. It has been replaced by
**[PainterPro](https://github.com/jweisner/Stationeers-PainterPro)**, a
standalone rewrite with the same controls and a more robust multiplayer
design. PainterPro is also on the
[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3840045914).

The fork's last release,
[v1.9](https://github.com/jweisner/Stationeers-NetworkPainter/releases/tag/v1.9),
is on the `multiplayer-fix` branch. The original mod is
[Elmotrix/NetworkPainter](https://github.com/Elmotrix/NetworkPainter).
